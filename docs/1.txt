
分析完成了。这是一个非常成熟的项目（法国和德国政府联合开发的开源协作文档编辑器 La Suite Docs）。以下是差距分析：

  ---
  我们 vs 大型项目的差距分析

  整体架构对比

  ┌──────────┬───────────────────────────────┬────────────────────────────────────────┐
  │   维度   │ collaborative-docs-v2（计划） │            docs（大型项目）            │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 后端     │ Node.js + Express             │ Django 5 + DRF（Python）
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 前端     │ React 18 + Vite               │ Next.js 16 + React 19                  │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 编辑器   │ TipTap 2.x                    │ BlockNote.js + TipTap 3.x              │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 协作层   │ y-websocket（裸 WebSocket）   │ HocusPocus（Yjs 增强服务器）
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 数据库   │ MongoDB                       │ PostgreSQL + S3 对象存储               │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 认证     │ 预留 schema，后续 JWT         │ OIDC（企业级单点登录）                 │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 状态管理 │ useState/useEffect            │ Zustand + React Query
  ├──────────┼───────────────────────────────┼────────────────────────────────────────┤
  │ 样式     │ 手写 CSS                      │ styled-components + Mantine + 设计系统 │
  ├──────────┼───────────────────────────────┼──────────────────────────────────
  │ 部署     │ 本地开发                      │ Docker + Helm + K8s                    │
  └──────────┴───────────────────────────────┴────────────────────────────────────────┘

  功能差距清单（按优先级排列）

  第一梯队：核心差距（课程项目应该有的）

  ┌──────────┬──────────────────┬────────────────────────────────┬────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │   功能   │       我们       │              docs              │                                                  差距说明                                                  │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 权限系统 │ 无               │ 5 级 RBAC + 3 级链接范围 + 3   │ docs 有 Reader/Commenter/Editor/Admin/Owner 五种角色，文档可以设为                                         │
  │          │                  │ 级链接角色                     │ Restricted/Au，链接角色可以独立配置，子文档继承父文档权限且只能收窄不能放宽              │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 文档归属 │ 无（随机用户名） │ User 关联 Document（creator    │ 文档有明确的创建者，权限基于用户身份                                                                       │
  │          │                  │ 字段）                         │                                                                                          │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 文档分享 │ 无               │ 邮件邀请 + 链接分享 +          │ 邮件邀请带角色和过期时间，用户首次登录自动转换邀请为权限                                                   │
  │          │                  │ 请求访问流程                   │                                                                                                            │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 评论系统 │ 无               │ Thread + Comment + Reaction    │ 线程化评论， 论支持富文本，emoji 反应                                                    │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 版本历史 │ 阶段二计划       │ S3 对象版本控制 + 分页列表 +   │ 文档内容存在   S3 版本控制实现版本管理                                                   │
  │          │                  │ 恢复                           │                                                                                                            │
  ├──────────┼──────────────────┼────────────────────────────────┼────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 用户认证 │ 预留 schema      │ OIDC 企业认证                  │ 我们计划用 JW 适合企业但复杂度高）                                                       │
  └──────────┴──────────────────┴────────────────────────────────┴────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  第二梯队：进阶差距（加分项）

  ┌─────────────────┬────────────┬──────────────────────────────────┬──────────────────────────────────┐
  │      功能       │    我们    │               docs               │                      差距说明                      │
  ├─────────────────┼────────────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 文档层级        │ 扁平列表   │ Treebeard 物化路径树             │ 支持子页面、文档树、移动、分离，子文档继承祖先权限 │
  ├─────────────────┼────────────┼──────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 软删除 + 回收站 │ 硬删除     │ 软删除 + 30 天回收站             │ 文档删除后进入回收站，可恢复，过期自动清理         │
  ├─────────────────┼────────────┼──────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 收藏夹          │ 无         │ DocumentFavorite                 │ 用户可以收藏文档，在首页快速访问                   │
  ├─────────────────┼────────────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 导入/导出       │ PDF + DOCX │ DOCX/ODT/PDF 导出 + DOCX/MD 导入 │ docs 用 BlockNote XL 导出器，格式保留更完整        │
  ├─────────────────┼────────────┼──────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 全文搜索        │ 文档名搜索 │ PostgreSQL trigram 相似度搜索    │ 搜索文档标题和摘要，模糊匹配                       │
  ├─────────────────┼────────────┼──────────────────────────────────┼────────────────────────────────────────────────────┤
  │ 文档摘要        │ 无         │ excerpt 字段自动生成             │ 文档列表显示摘要预览                               │
  └─────────────────┴────────────┴──────────────────────────────────┴──────────────────────────────────┘

  第三梯队：生产级差距（超出课程范围）

  ┌──────────────┬────────────────┬──────────────────────────────────────┬─────────────────────────────────────────────────────┐
  │     功能     │      我们      │                 docs                 │                      差距说明                       │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ AI 集成      │ 无             │ OpenAI/Mistral + SSE 流式输出        │ 选中文本→AI 重写/翻译/优化，AI 光标像协作者一样编辑 │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤

  ├──────────────┼────────────────┼──────────────────────────────────────┼───────────────────────────────────┤

  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ 安全加固     │ 无             │ CSP/CORS/限流/恶意软件扫描           │ 生产级安全防护                                      │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ 国际化       │ 无             │ 17 种语言 + Crowdin 翻译平台         │ 多语言支持                                          │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ 邮件模板     │ 无             │ MJML 模板 + HTML/文本双格式          │ 邀请、通知等邮件                                    │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ 可观测性     │ 无             │ Sentry + PostHog + django-silk       │ 错误追踪、用户分析、性能监控                        │
  ├──────────────┼────────────────┼──────────────────────────────────────┼─────────────────────────────────────────────────────┤
  │ 离线编辑     │ IndexedDB 缓存 │ Service Worker + Workbox + IndexedDB │ 完整的 PWA 离线能力                                 │

  建议的课程项目路线图

  考虑到这是课程项目，不可能做到 docs 项目的规模，但可以选取最有展示价值的功能：

  ┌────────────────┬──────────────────────────┬──────────────────────────────┐
  │      阶段      │           功能           │     对标 docs 的哪些能力     │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段一（当前） │ TS + TipTap + 单通道 Yjs │ 编辑器内核升级               │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段二         │ MongoDB + 版本历史       │ 持久化 + 版本管理            │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段三         │ 用户注册登录 + 文档归属  │ User 模型 + Document.creator │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段四         │ 权限系统 + 分享          │ RBAC + 邮件邀请 + 链接分享   │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段五         │ 评论系统                 │ Thread + Comment             │
  ├────────────────┼──────────────────────────┼──────────────────────────────┤
  │ 阶段六（可选） │ 文档树 + 软删除 + 收藏   │ 层级管理 + 回收站            │
  └────────────────┴──────────────────────────┴──────────────────────────────┘
